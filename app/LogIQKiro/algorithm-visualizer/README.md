# Algorithm Visualizer

An interactive web application that helps users understand algorithms through visual step-by-step execution.

## Features

- Visualize sorting algorithms step-by-step
- Control execution speed and step through algorithms manually
- Input custom data or generate random datasets
- View algorithm information including pseudocode and complexity analysis
- Compare different algorithms side-by-side (coming soon)
- Create and test custom algorithms (coming soon)

## Implemented Algorithms

- Bubble Sort
- Insertion Sort
- Selection Sort

## Technologies Used

- React
- TypeScript
- HTML5 Canvas for visualization
- Tailwind CSS for styling

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173`

## Usage

1. Select an algorithm from the dropdown menu
2. Input your data or use the quick generate buttons
3. Use the control panel to play, pause, reset, or step through the algorithm
4. Observe the visualization and follow along with the highlighted pseudocode

## Project Structure

- `/src/algorithms` - Algorithm implementations
- `/src/components` - React components
- `/src/types` - TypeScript interfaces and types
- `/src/utils` - Utility functions
